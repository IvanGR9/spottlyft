# Gestión del Proyecto — SpottLyft

## Herramienta utilizada

Para la gestión del proyecto se utiliza **Trello** con un enfoque inspirado en Kanban. El tablero está organizado en cinco columnas que representan el estado de cada tarea.

## Estructura del tablero

- **Backlog:** Todas las funcionalidades y tareas identificadas para el proyecto
- **Todo:** Tareas priorizadas y listas para empezar en el corto plazo
- **In Progress:** Tareas en desarrollo activo
- **Review:** Tareas completadas pendientes de revisión y pruebas
- **Done:** Tareas completadas y verificadas

## Organización del trabajo

Las tareas se dividen en funcionalidades principales. Cada funcionalidad se mueve por las columnas según avanza su desarrollo. Al ser un proyecto individual se prioriza la entrega continua sobre los sprints fijos, por eso se eligió Kanban sobre Scrum.
